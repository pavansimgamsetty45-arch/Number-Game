# Project 1 – Number Game (Java)

This project is part of my **Java Internship**.

## 📌 Project Description

A simple Number Game implemented using Java that allows users to:

- Generate a random number between 1 and 100
- Enter guesses through the console
- Receive feedback if the guess is too high or too low
- Continue guessing until the correct number is found
